## 어떤 문제였나

인플루언서 마케팅의 성과를 볼 때 흔히 쓰는 지표는 좋아요와 댓글 수입니다. 그런데 댓글 1,000개가 달렸다고 해서 1,000명이 사고 싶어 한 건 아닙니다.

댓글에는 여러 종류가 섞여 있습니다.

- "예쁘다", "❤️❤️" — 단순 반응
- "어디서 사요?", "가격 얼마예요?" — **구매 의도**
- "@친구야 이거 봐" — 공유
- 스팸, 광고

**단순 반응과 구매 의도를 구분해야** 어떤 콘텐츠가 실제로 판매로 이어지는지 알 수 있습니다.

분류가 어려운 이유도 있었습니다.

- 다국어가 섞입니다
- 이모지만 있는 댓글이 많습니다
- 문장이 매우 짧습니다 ("얼마?")

짧고 문맥이 없는 텍스트라 단일 분류 방식으로는 오탐이 많았습니다.

## 어떻게 풀었나

### 규칙과 모델을 결합

두 방식을 나눠 맡겼습니다.

| 방식 | 담당 | 예시 |
|---|---|---|
| **정규식 규칙** | 명확한 표현 | "얼마", "어디서 사", "링크", "구매" |
| **KcBERT 분류** | 문맥 판단이 필요한 댓글 | 애매하거나 우회적인 표현 |

"얼마예요?"는 규칙으로 잡으면 됩니다. 모델을 부를 이유가 없고, 규칙이 더 정확합니다.

반대로 "이거 지난번에 놓쳤는데..."는 문맥을 봐야 합니다. 이런 것만 모델로 보냅니다.

**한국어 소셜 텍스트에 KcBERT를 쓴 이유**는 이 모델이 댓글·구어체 데이터로 학습됐기 때문입니다. 표준어 코퍼스로 학습한 모델은 줄임말과 신조어가 많은 댓글에서 약합니다.

### 수집과 분석을 분리

브라우저 수집은 자주 실패합니다. 로그인 상태, 로딩 지연, 구조 변경.

**수집 실패가 모델 추론까지 막지 않도록** 단계를 나눴습니다.

```
원문 저장 → 정제 → 분류
   ↑          ↑       ↑
 각각 독립적으로 재실행 가능
```

수집이 절반에서 끊겨도 이미 모은 것은 분석할 수 있고, 분류 로직을 고쳐도 다시 수집할 필요가 없습니다.

### 다국어 정리

언어 필터를 앞단에 두어 대상 언어를 분리하고, 이모지만 있는 댓글을 별도로 처리합니다.

## 결과

| 영역 | 내용 |
|---|---|
| 수집 | 게시물·릴스 댓글 |
| 정제 | 언어 필터 · 이모지 처리 |
| 분류 | 규칙 + KcBERT 하이브리드 |
| 집계 | 구매 의도 비율 산출 |

## 이 프로젝트에서 배운 것

**짧은 텍스트는 문맥이 없어서 어렵습니다.** "얼마?"는 두 글자지만 명확한 구매 신호이고, "좋다"는 세 글자인데 무엇이 좋다는 건지 알 수 없습니다. 길이가 정보량과 비례하지 않습니다.

**전부 모델에 넘기지 않는 편이 정확했습니다.** 명확한 패턴은 규칙이 더 잘하고 더 쌉니다. 모델은 규칙이 감당 못 하는 부분에 쓸 때 값어치가 있습니다. 이 판단은 [Bid Master의 엑셀 파싱](../bid-master/decisions.md#04-llm을-기본-경로가-아니라-마지막-폴백에-두었습니다)에서도 같았습니다.

**수집과 분석을 붙여 두면 둘 다 못 쓰게 됩니다.** 실패 특성이 완전히 다른 두 작업을 분리하는 것이 재실행 가능성의 조건이었습니다.
